# 🐾 Adopta una Mascota

## Descripción del Proyecto
Página web sencilla desarrollada en HTML y CSS para un refugio de animales, diseñada para promover la adopción responsable de perros, gatos y otras mascotas. El sitio cuenta con un diseño responsivo para adaptarse correctamente a dispositivos móviles.

## Secciones de la Página
1. *Encabezado y Menú:* Navegación fija con efectos visuales y enlaces a las secciones
2. *Sección Principal (Hero):* Eslogan llamativo, degradado de fondo y botón de llamada a la acción
3. *Sobre Nosotros:* Misión del refugio, datos curiosos y valores institucionales
4. *Tarjetas de Adopción:* Presentación de las mascotas disponibles con imágenes y descripciones
5. *Visítanos:* Horarios, dirección, botón de cómo llegar y mapa interactivo
6. *Contacto y Pie de Página:* Formulario interactivo y enlaces a redes sociales

## Comandos de Git Utilizados
Durante el desarrollo del proyecto en equipo se utilizaron los siguientes comandos principales:
* git init / git clone
* git checkout -b <nombre-rama>
* git add .
* git commit -m "mensaje"
* git push origin <rama>
* git pull
* git merge <rama>

## Conclusión del Equipo
*¿Qué fue lo más difícil del trabajo con ramas?*
Lo más difícil fue coordinarnos al principio para entender cómo evitar conflictos al modificar distintos archivos o secciones a la vez, así como aprender a integrar correctamente cada rama (merge) en la rama principal (main). Sin embargo, practicarlo nos ayudó a entender el flujo de trabajo colaborativo en Git.]
